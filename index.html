Features

Production-Grade Data Pipeline

Built for scale, fault-tolerance, and data quality

🚀

Massive Bulk Extraction

Concurrent scraping architecture that scales to 500,000+ records with infrastructure scaling only

🛡️

Anti-Bot Navigation

Playwright-based JS rendering, human-like pacing, and compliant proxy integration for protected sources

🤖

Multi-Tier LLM Fallback

Gemini → Groq → DeepSeek chain with exponential backoff and jitter for 429/413 handling

🔍

Entity Resolution

Canonicalizes messy strings (OpenAI, Inc. → OpenAI) using exact, alias, and fuzzy matching

⏱️

Freshness Tracking

SQLite dedupe store with SHA-256 hashing ensuring no duplicate processing across nodes

📈

Dynamic Metrics

Real-time GitHub star tracking and rigorous ISO-8601 timestamp normalization
